# Raman TEP/DIMP/DMMP — dataset preparation

This repository currently contains phase 1 of the project: inspection,
leakage-safe group splitting, metadata handling and SNV preprocessing for the
experimental Raman spectra of TEP, DIMP and DMMP.

See [README_DATASET_PREPARATION.md](README_DATASET_PREPARATION.md) for dataset
placement, reproducible commands and the preprocessing contract.

The original Mendeley workbooks, generated datasets, models, benchmark logs
and deployment artifacts are intentionally excluded from this initial phase.
